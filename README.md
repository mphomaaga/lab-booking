# lab-booking

Campus lab booking pilot: students book one-hour slots in Lab A, Lab B and Lab C (30 seats each), and admins view bookings and close a lab for a day. The backend is Python 3.12 with FastAPI and SQLite, the frontend is React with Vite and TypeScript. It is also the test material for a multi-agent build pipeline.

See `docs/architecture.md` for how to run the app and the tests, the folder layout and the configuration.
